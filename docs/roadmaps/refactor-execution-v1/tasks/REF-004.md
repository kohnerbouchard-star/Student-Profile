- **REF004-OBS-01:** Admin progress forwarding drops the filter query; the direct Staff handler supports those filters. Any correction needs separate behavior-change acceptance.
- **REF004-OBS-02:** Legacy approval reviews before reward issuance. A reward rejection can follow a successful review; the two calls are not one transaction. Review-only aliases must not gain this side effect.
- **REF004-OBS-03:** Staff review does not turn the retry header into a payload-bound receipt. Repeated/changed review actions can execute again; no conflict guarantee is invented.
- **REF004-OBS-04:** Credential replacement sends no request-id/idempotency-key RPC parameter. Identifier-only writes do not replace credentials or revoke sessions.

Receipt stubs prove adapter invocations and output handling, not SQL locks, conservation or race safety. The old Staff reward-then-mark implementation is not substituted for Admin's atomic authority.
