# REF-038 — Extract one pure Stock-engine calculation family

Status: PLANNED. Risk: R3. Dependencies: REF-005. Maps to ARCH-206.

## Read first

`backend/src/domains/stocks/calculations/stockMarketEngine.ts`, `seededRandom.ts`, engine contracts and existing engine tests/simulations. The observed engine exports `OFFICIAL_ECONOVARIA_COUNTRY_CODES`, `SUPPORTED_STOCK_MARKET_SECTOR_KEYS`, `EconovariaCountryExposureProfile` and `ECONOVARIA_COUNTRY_EXPOSURE_PROFILES`.

## Allowed change

Only the country-exposure profile/resolution family and exact engine imports/tests. Proposed `stocks/calculations/countryExposureProfiles.ts`; retain approved compatibility re-exports where required. No whole-engine rewrite, coefficient/sector/country changes, random algorithm, tick order, rounding or seed-content edits. Budget: eight meaningful files.

## Implementation

1. Identify all callers of the named constants/type/profile table and the smallest associated pure resolver/calculation. Record current object/iteration order and any initialization behavior.
2. Move that family without altering a key, coefficient, array order, numeric literal or fallback rule. Distinguish mechanical moved lines from semantic changes in the diff.
3. Reuse existing types; keep imports acyclic and avoid pulling runtime/persistence modules into the pure calculation module. Preserve public exports through one-way re-export only when current callers need them.
4. Compare full engine output on fixed baseline inputs/seeds before and after; extraction must not change random-number call order, tick timestamps, rounding or serialized component explanations.
5. Add direct cases for each official country, supported sector aliases and existing unknown-input behavior without inventing new economic policy.

## Acceptance and validation

Same seed/input produces the same full tick output and explanation; no profile value/order drift. The engine has one smaller pure family, not a parallel implementation. Run engine/simulation tests through their current registration, backend `test:stock-market-calendar`, `test:player-market-assets`, Player `market-flow`, `market-holdings`, typecheck and architecture checks.

## Stop / rollback

Stop if extraction changes object initialization or RNG sequence and parity cannot be proven. Do not update golden expected prices to excuse drift. Revert the move/re-export only; no market data or seed changes.
