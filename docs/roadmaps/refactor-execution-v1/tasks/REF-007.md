# REF-007 — Replace Contract progress GET forwarding with a local adapter

Status: PLANNED. Risk: R2. Dependencies: REF-005. Maps to ARCH-400/ARCH-700. Recheck #668 context ownership.

## Read first

`backend/supabase/functions/admin-api/gameRoutes.ts::handleGameRead` and its `contractProgressMatch`; `common.ts::proxyClassroom`; `backend/src/domains/contracts/api/staffContractHttpHandler.ts`; existing Contract progress read/repository tests; REF-004 fixture.

## Allowed change

Only the GET `/games/:game/contracts/:contract/progress` adapter, a proposed `admin-api/contractProgressReadOperation.ts`, the existing Contracts-owned read seam if extraction is necessary, and tests. No review/reward mutation, Store/Settings migration or blanket proxy deletion. Budget: ten meaningful files.

## Implementation

1. Trace the downstream `/staff/game-sessions/:game/contracts/:contract/progress` behavior: auth, ownership, identifiers, filters, ordering, pagination and response envelope.
2. Reuse its current Contracts read use case/repository directly under the Admin guard. If it exists only in an HTTP handler, extract the smallest read operation without changing SQL or its scope predicates.
3. Adapt the approved Admin context explicitly; do not cast an untrusted browser identity into Staff authority. Preserve any security/throttling checks previously enforced downstream.
4. Replace just the selected `proxyClassroom` call with local invocation and current JSON/header mapping. Keep other aliases and proxy paths unchanged.
5. Record the removed network hop and compare both implementations using the same synthetic fixtures. Assert no outbound Classroom fetch for this route and no increase in database calls.

## Acceptance and validation

Valid owner, missing contract, wrong game, unauthorized Staff, malformed identifier, empty progress and repository failure retain their established response contract. Reads remain read-only. Run backend `test:admin-api`, `test:player-contract-acceptance`, `test:player-contract-lifecycle`, relevant Admin Contracts tests and shared typecheck/auth/architecture gates.

## Stop / rollback

Stop if downstream permission/rate-limit parity is unresolved or a schema change is proposed. Revert the local adapter and its wiring as one source change; no data correction is involved. Do not claim Classroom retirement from one removed call.
