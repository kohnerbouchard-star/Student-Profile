## Implementation

1. Trace each public method/path through browser caller, BFF, auth guard, Edge dispatcher, application handler, repository and SQL/RPC. Separate canonical routes, aliases, compatibility-only routes and externally callable workers.
2. For every Classroom dependency classify HTTP forwarding, source import, test configuration, browser alias, deployment requirement or historical mention. A documentation reference is not a live caller; an externally callable endpoint is not dead because imports are zero.
3. Record the precise residual routes visible in `gameRoutes.ts`: progress GET; decision/submissions-review/progress-review aliases; reward issue; access-code reset. Verify any additional proxy calls rather than assuming this is the exhaustive list.
4. Trace HTML script tags, generated-bundle inputs, dynamically constructed imports, fetch interception, DOM observers and event listeners. Record mount/dispose ownership and which browser surface loads each shim.
5. Map each route's actor/game resolution, permission, identifier translation, rate-limit and idempotency enforcement point. Record current response/header boundaries and external consumers as unknown unless evidenced.
