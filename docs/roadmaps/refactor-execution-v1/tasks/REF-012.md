# REF-012 — Replace the legacy Attendance fetch bridge with an explicit adapter

Status: PLANNED. Risk: R2. Dependencies: REF-005. Maps to ARCH-500/ARCH-700.

## Read first

`admin/attendance-reward-settings-route-bridge-v2.js`, `admin/attendance-reward-settings-v4.js`, `admin/attendance-reward-save-controller-v3.js`, canonical Attendance API client and actual HTML/source-bundle loading graph from REF-002. Read current Attendance save/browser tests.

## Allowed change

One Attendance request lifecycle, its explicit mount/client call site, focused tests and the proven source-owned script reference. Proposed adapter, only if needed: `admin/attendance-reward-request-adapter.js`. Do not modify the generated Admin bundle, reward formula, settings schema or unrelated global fetch wrappers. Budget: ten meaningful files.

## Implementation

1. Confirm this bridge is actually loaded. If not, record it as a deletion candidate for REF-015 instead of creating a replacement feature.
2. Characterize the exact matched request, request-body normalization, idempotency header, response event and save/error presentation. Identify who owns its listener and disposal.
3. Move its request translation into an explicit function invoked by the Attendance save controller using the current authenticated Admin transport.
4. Preserve payload casing, currency/formula fields, CSRF/session/idempotency handling, disabled/save states, retry messaging and required custom lifecycle events. Do not intercept unrelated requests.
5. Remove only this bridge's global fetch assignment after the explicit path is proven. Keep necessary DOM observation until an equivalent mount lifecycle exists; record that residual dependency.

## Acceptance and validation

A successful save produces one network mutation and one owned refresh; duplicate clicks, malformed settings, permission denial, dependency errors and remounts do not duplicate listeners or writes. Global fetch identity is unchanged by the replacement. Run affected Attendance/Admin unit/browser cases, root `test:admin-local-mutation-ui`, `test:admin-v2`, `audit:interaction-wiring`, `audit:assets` and shared guards.

## Stop / rollback

Stop if the only writable owner is a generated/minified bundle or if the bridge's event consumers are unresolved. Revert source adapter and script wiring together. Do not remove an observer solely because the inventory calls it a shim.
