# REF-040 — Expose a minimal generic Markets calculation boundary

Status: PLANNED. Risk: R2. Dependencies: REF-038. Maps to ARCH-206/ARCH-402.

## Read first

`backend/src/domains/markets/calculations/bondMath.ts`, its current contracts/tests/callers, generic Markets validation modules and the Stocks runtime boundary. Confirm actual live consumers before changing import paths.

## Allowed change

The public boundary for one pure calculation family, initially bond valuation math and only its existing callers. Proposed `markets/index.ts` if absent, with explicit named/type-only exports. No new instrument type, pricing formula, rate convention, financial-market listing authority, SQL or runtime initialization. Budget: eight meaningful files.

## Implementation

1. Classify exported helpers as pure calculations versus runtime state/IO. Record units, precision, error handling and all current importers of the selected bond-math family.
2. Expose only already-supported calculation/types through the minimal public boundary; do not export simulation fixtures, mutable state or whole directories.
3. Change the exact consumer import specifiers without changing invocation or values. Keep Stocks as the owner of market runtime and Business as the owner of corporate share authority.
4. Verify module import is side-effect-free and introduces no cycle or enlarged runtime dependency closure beyond the chosen family.
5. Compare existing zero/negative/invalid/nonfinite input behavior, boundary maturities/rates and round-trip valuation cases. Preserve existing rejection semantics rather than correcting formulas under a refactor label.

## Acceptance and validation

Selected pure consumers use one public seam and produce identical numeric/error outputs. No duplicate pricing authority or new IO exists. Run the current bond-math/generic Markets tests, relevant Stocks engine/market-asset tests, full typecheck/smoke and architecture audits. Record unconsumed calculation modules as candidates, not automatically dead.

## Stop / rollback

If the selected family has no production consumer, classify it against approved feature scope before moving or deleting it. Stop on any formula change. Revert only exports/imports; no price history or financial data changes.
