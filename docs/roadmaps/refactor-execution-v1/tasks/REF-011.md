# REF-011 — Detach canonical test suites from Classroom-owned Deno configuration

Status: PLANNED. Risk: R2. Dependencies: REF-006. Maps to ARCH-400/ARCH-700. Recheck #668/#736 package/composition ownership.

## Read first

`backend/package.json`, `backend/supabase/functions/deno.json`, Classroom/Admin Deno configurations and shared lockfile; current Edge-root typecheck script; each migrated suite's read/env/network permissions and import maps.

## Allowed change

One neutral configuration seam and exact test-script/config references only. Prefer the existing neutral configuration; create a proposed `_config/deno.player.json` only when effective options differ and a neutral owner is necessary. Preserve the lockfile, dependency versions and source-test permissions. Budget: ten meaningful files per child; no runtime router or workflow edits.

## Implementation

1. Compare effective compiler options, import maps, inherited configuration and permissions. Do not assume two JSON files are equivalent because both typecheck.
2. Reuse/extract the common configuration without changing dependency resolution. Validate a representative Player suite against old and neutral configs before changing registration.
3. Migrate suite references in bounded groups: Player scope/security; read/notification domains; economic/stateful domains. If multiple groups would enlarge review, register REF-011a/b/c with exact script keys and separate evidence before editing.
4. Keep genuine Classroom composition tests and their explicit source-read permissions classified as compatibility tests; a test reading the old router is different from a canonical suite borrowing its compiler config.
5. Add a ratchet against new unrelated suites depending on Classroom config. Record all remaining references by category rather than using a blanket text replacement.

## Acceptance and validation

Each migrated suite runs the identical test set with identical permissions and frozen dependency identities. Full backend smoke and `typecheck:all` pass. No lockfile regeneration or broad allow-net/env permission is introduced. All children must finish before the parent closes; required compatibility tests remain green until REF-048 retires their target under evidence.

## Stop / rollback

Stop on any effective-resolution mismatch or active package owner collision. Revert only migrated configuration references. Do not remove tests or widen permissions to force parity; do not delete Classroom configuration while a required consumer remains.
